Privacy policy

Cerebro Planner · last updated 28 September 2026

  • Who uses it: only its owner, Vijay Tholpadi. It is a personal tool, not a public service.
  • What it accesses: the owner's Google Calendar list and events (and basic profile info to label the connected account). It creates or edits calendar events only when the owner does so in the planner.
  • Where data is stored: on the owner's own computer, in a local database. No data is sent to any server run by the developer.
  • Sharing: none. Data is never sold, shared with third parties, or used for advertising or AI model training.
  • Google API data: use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoke access: any time at myaccount.google.com/permissions; local data can be deleted by disconnecting the calendar in the planner.
  • Contact: open an issue at github.com/vijaytholpadi/cerebro-planner.
